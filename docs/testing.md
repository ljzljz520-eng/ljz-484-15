## 3. 接口测试 (API Testing)
使用 Swagger 进行接口验证：
- `GET /api/novels`: 返回 200，JSON 包含分页数据。
- `GET /api/novels/1`: 返回书籍详情及章节数据。
- `GET /api/chapters/1`: 正确返回正文字符串。
- `GET /api/author/stats`: 返回 200，包含 `novelCount`、`draftChapterCount`、`publishedChapterCount`、`lastUpdatedAt`、`weeklyWordCount`、`weekStart`（本周一 00:00）。
- `GET /api/author/chapters`: 返回分页章节列表，列表项含所属作品标题与字数，不含正文全文。
- `GET /api/author/chapters?status=DRAFT`: 仅返回草稿章节，`total` 与列表一致。
- `GET /api/author/chapters?weekly=true` 与 `?weekly=1`: 两种写法返回结果一致，均为本周一 00:00 后创建的章节。
- `GET /api/author/chapters?status=PUBLISHED&weekly=true`: 组合筛选生效。
- 异常场景：停止后端服务后请求 `/api/author/stats`，前端工作台展示可见错误提示而非静默空白。
